# HR Controlling | Workforce Planning & Salary Cost Analysis 2025

## Project Overview

An Excel-based HR Controlling project focused on workforce planning, personnel cost monitoring, budget variance analysis, and salary increase forecasting.

## Excel Skills Demonstrated

- HR KPI reporting: Headcount and FTE
- Budget vs. Actual variance analysis
- SUMIFS and structured Excel references
- Salary forecasting and scenario analysis
- Conditional formatting and charts
- Management insights and recommendations

## Workbook Structure

- **Employee_Data:** Employee-level workforce data
- **HR_KPI_Summary:** Workforce KPIs and departmental salary costs
- **HR_Budget_vs_Actual:** Departmental budget variance analysis
- **HR_Forecast_2025:** Salary increase scenarios
- **HR_Management_Insights:** Financial findings and management recommendations
